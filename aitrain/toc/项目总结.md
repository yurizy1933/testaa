# 相似度匹配器项目总结

## 项目概述

本项目实现了一个完整的相似度匹配器系统，能够通过正弦相似度和余弦相似度计算相似向量，筛选faiss_index和case_faiss_index中相似的值，并生成符合要求的训练数据。

## 核心功能

### 1. 相似度计算
- **余弦相似度**: 计算向量方向的相似性
- **正弦相似度**: 计算向量的正交性
- **综合相似度**: 结合两种相似度的加权计算

### 2. 向量匹配
- 从 `faiss_index` 中提取需求文档向量
- 从 `case_faiss_index` 中提取测试用例向量
- 建立一对多的相似关系
- 根据相似度阈值筛选结果

### 3. 训练数据生成
- 按照指定格式生成训练数据
- 包含完整的对话上下文
- 支持JSON格式输出

## 核心模块详解

### SimilarityMatcher 类

#### 主要方法

1. **`__init__`**: 初始化相似度匹配器
   - 设置FAISS索引路径
   - 初始化向量存储和数据库管理器

2. **`calculate_cosine_similarity`**: 计算余弦相似度
   - 使用点积和向量范数计算
   - 处理向量维度问题

3. **`calculate_sine_similarity`**: 计算正弦相似度
   - 基于余弦相似度计算
   - 使用数学关系: sin²(θ) + cos²(θ) = 1

4. **`find_similar_pairs`**: 查找相似向量对
   - 提取所有向量
   - 计算相似度矩阵
   - 筛选和排序结果

5. **`generate_training_data`**: 生成训练数据
   - 获取需求和测试用例信息
   - 构建标准格式的训练数据

6. **`run_similarity_matching`**: 运行完整流程
   - 协调所有步骤
   - 提供详细的进度信息

#### 技术特点

- **向量处理**: 支持不同维度的向量输入
- **内存优化**: 分批处理大量向量
- **错误处理**: 完善的异常处理机制
- **性能优化**: 使用numpy进行高效计算

## 技术实现细节

### 相似度计算算法

1. **余弦相似度**:
   ```
   cos(θ) = (A·B) / (||A|| × ||B||)
   ```

2. **正弦相似度**:
   ```
   sin(θ) = √(1 - cos²(θ))
   ```

3. **综合相似度**:
   ```
   combined = 0.7 × cosine + 0.3 × sine
   ```

### 向量处理流程

1. **向量提取**: 从FAISS索引中读取所有向量
2. **维度统一**: 确保向量维度一致
3. **相似度计算**: 计算每对向量的相似度
4. **结果筛选**: 根据阈值筛选相似对
5. **排序输出**: 按相似度降序排列

### 数据库集成

- 使用 `ThreadSafeDatabaseManager` 进行数据库操作
- 支持多线程安全访问
- 自动处理连接池和重试机制
